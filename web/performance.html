⚠ Caution: do not run this while the model is in use. The test makes the model {{if .Embedding}}work through a text{{else}}write text{{end}}. If a person or a program is using it, the test can slow their work down or wait in line behind it, and your numbers will come out too low. It can also use extra memory, and on a full machine Ollama may unload another model to make room. Run it when Ollama is idle.

{{/* A second warning when the machine looks busy right now. */}} {{if .BusyReason}}

⚠ The machine looks busy right now: {{.BusyReason}}. The figures of a test would be unreliable.

{{end}} {{/* What the test does. */}}

What the test does, in order:

  1. One warm-up request loads the model from disk. Its load time is reported as the cold figure.
  2. Three timed requests follow with the model in memory; each result is the median of the three.
  3. The monitor reads what Ollama reports about the loaded model, and what the machine looks like.
  4. The model is unloaded again, so memory is left as it was found.

The test uses the same fixed prompt every time ({{if .Embedding}}an embedding model gets the same text{{else}}about 200 tokens; each answer is capped at 64 tokens{{end}}). Time needed: {{.Duration}}. Only numbers are saved, never any text.
